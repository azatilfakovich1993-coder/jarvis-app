Политика конфиденциальности Jarvis

Действует с 5 октября 2026 года.

Кто пользуется приложением

Jarvis — личное приложение одного человека (владельца). Оно не продаётся и не предлагается другим пользователям.

Какие данные используются

  • Gmail — письма владельца: чтобы находить нужные письма, делать сводки, готовить и отправлять письма. Отправка — только после явного подтверждения владельцем.
  • Google Календарь — события владельца: чтобы показывать расписание, искать свободное время и создавать события после подтверждения.
  • Адрес почты аккаунта Google — чтобы показывать, с какого адреса уйдёт письмо.
  • Заметки, напоминания и сообщения в чате, которые владелец сам вводит в приложении.

Где хранятся данные

Данные хранятся на сервере, принадлежащем владельцу. Ключи доступа к Google хранятся только в зашифрованном виде. Данные не продаются, не передаются третьим лицам и не используются для рекламы.

Обработка текста

Чтобы понимать запросы и готовить ответы, тексты запросов и нужных писем передаются языковой модели GigaChat (ПАО Сбербанк) только в объёме, необходимом для выполнения запроса.

Соответствие правилам Google

Использование и передача информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ и удалить данные

Доступ можно отозвать в любой момент в приложении (Меню → Сервисы → Отключить) или в настройках аккаунта Google: myaccount.google.com/permissions. При отключении сохранённые ключи доступа удаляются.
